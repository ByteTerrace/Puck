# World name registry

Generated by `puck registry` from `WorldNameRegistry` over `WorldJsonContext`; do not hand-edit.
`puck registry --check` fails when this file disagrees with the model.

Every document field that carries a state, zone, rule, table, pattern, topology, generator, field, or
dynamics name. `[]` is a list element; `[name]` is a `$type` arm; `{tokens}` is an expression's postfix
spelling; `{row}` is a reaction scalar's row form. A path ending in `…` re-enters a shape listed above it.
An aliased import (`imports[].as`) prefixes every `Declares` site with `<alias>_` and rewrites every other
role's names to match. Facet is the export list (`exports.reads`/`actions`/`bindings`) that admits a host
reference through the field to an imported module's name; see `src/Puck.World.Schema/README.md`.
