# Reference game

The reference game is Puck's concrete design target: a shared world that makes
the engine's world model useful to play, author, and verify. This section
collects the design requirements, proposed engineering work, visual direction,
and dated evidence. Engine concepts and current contracts remain in the
[manual](../README.md); these pages explain how the reference game uses them.

- [Reference game design](design.md)—gameplay requirements and project decisions.

- [Game development plan](../plans/game-development.md)—sequencing, detailed game topic plans, future waves, and federation work.

- [Art and visual design](art/README.md)—character briefs, concept packages, and visual references.

- [Game development milestones](../development/game-milestones.md)—dated verification evidence from earlier game development.
