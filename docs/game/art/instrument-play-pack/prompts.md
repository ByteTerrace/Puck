# Moth instrument and dance generation prompts

Codex used the built-in `image_gen.imagegen` tool with one opaque PNG per
call. Reference images supplied character, prop or environment continuity.
The prompts below are the submitted text, grouped by panel. See the
[written audit](review.md) for selection and review status.
