# Wire and replication for federated worlds

Build the wire-record generator first. Use it to encode complete checkpoint records and to prove that every field has a bounded representation. Then use the same definitions to send field deltas between the body images Puck already acknowledges. Give the local seat an exact continuation, give observers a byte-budgeted view, and measure compression on the resulting traffic. One zone can have thousands of viewers, one player can observe several zones through portals, and each zone can have a different operator. The design needs to bound the work of each relationship and reuse work when views coincide.

**Puck design.** Compare canonical fields after composing the recipient's view. Generate a mask per body record, starting with one bit per independent field and a shared bit for fields that must change atomically. Capture stable pose and continuity separately from one-shot events so a resend cannot replay a teleport or cue as a new event. Use a sorted slot delta for addressing within a stream, and include incarnation on create or replace. An acknowledged definition can bind local tokens for stable strings and prototype pins. If it has not arrived, send the self-contained form. Canonicalize padding and ordering for hashing. Start with one acknowledged baseline. Quake's whole snapshot history, Tribes' dirty-group resend and Unity's three-snapshot predictor offer different memory and loss trade-offs. A third baseline pays only if reduced bytes exceed the cost of retaining and accessing it.

For the exact path, take `FixedQ4816.Value` at the simulation source. The position in `EntitySnapshot` is already a float and cannot recover discarded bits. For a proven half-open interval of 1,024 units, subtract an exact origin and encode the 26-bit unsigned raw offset. Use a wider intermediate for subtraction and reconstruction. For temporal deltas, try a signed 10-bit raw difference from the acknowledged value, with a tag and a full signed 64-bit raw escape. `[-512, 511]` spans about 7.8 mm on either side if a world unit is a meter. That is the short range, with all 16 fractional bits retained. At the signed endpoints an unchecked subtraction can wrap a large difference into a tiny one. Use widened arithmetic and reject a decoded value outside the field's domain. Treat origins and bounds as schema or disclosed content with an agreed identity. Use a self-contained absolute record across an origin change, discontinuity or incarnation change. The ordinary path decodes bounded, small records and combines them with an in-memory baseline, so generate a direct codec for that path. ## Compression for small packets and bulk records

Use raw packed snapshots as the baseline. DEFLATE uses LZ77 and Huffman coding. Its zlib framing adds a header and checksum, and zlib also supports preset dictionary bytes. Zstandard frames have their own headers and process windows, with provision for a prepared dictionary containing both history and entropy tables. A short, already packed delta may offer little redundancy, so even positive size savings before framing can disappear on the wire. Larger primers, definition snapshots and checkpoint chunks are better first candidates. The zstd project's Silesia throughput numbers quoted in audit finding 11 come from large files. Its small-data example uses GitHub user records, a separate corpus. Neither determines the smallest profitable Puck packet. [DEFLATE, RFC 1951](https://datatracker.ietf.org/doc/html/rfc1951), [zlib framing, RFC 1950](https://www.rfc-editor.org/rfc/rfc1950.html), [zlib dictionary API](https://zlib.net/manual.html), [Zstandard, RFC 8878](https://www.rfc-editor.org/rfc/rfc8878.html), [zstd benchmarks and small-data example](https://github.com/meta/zstd/blob/dev/README.md).

Compare raw bytes, fast DEFLATE, fast zstd, and each supported dictionary mode on the same independently decodable frame boundaries. Train offline on a representative set of post-delta, already disclosed samples. Separate primers, steady motion, dense events and bulk checkpoints when the distributions differ. Hold out entire routes, worlds or sessions so adjacent ticks do not leak into both training and validation. Use public or synthetic training material for a shared dictionary. Publish its bytes by content pin, map its short ID after acknowledgment, and fall back to raw on an unavailable dictionary. Never couple consecutive packet decodes by feeding an unacknowledged stream history into compression. Select compressed bytes only if their total cost wins after headers, dictionary identifiers and amortized dictionary delivery.
