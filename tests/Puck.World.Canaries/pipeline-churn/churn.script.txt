# Paused and reset, the last loaded graph renders submission 2. Before the capture creates its readback staging buffer,
# which the instance owns from then on, the instance owns exactly its installed graph; then submission 2 is captured.

pipeline.wait feedback submitted 1 10
pipeline.step feedback

pipeline.inspect feedback
