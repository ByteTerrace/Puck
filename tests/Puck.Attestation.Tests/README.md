# Puck.Attestation.Tests

This suite exercises signed attestation encoding, verification, key chains,
trust ownership, sequence and clock handling, sealed attestations, parser
laxity, conformance profiles, and durable replay transactions. The
interchange fixtures include an independent implementation so wire behavior
is checked across implementations.

## Running

```powershell
dotnet test tests/Puck.Attestation.Tests/Puck.Attestation.Tests.csproj -c Release
```
