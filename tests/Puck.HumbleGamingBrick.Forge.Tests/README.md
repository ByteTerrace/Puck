# Puck.HumbleGamingBrick.Forge.Tests

This xUnit v3 suite verifies the Humble cartridge compiler's boot ROM policy,
presentation data, SM83 labels, and emitted document behavior. It exercises
the Forge contract and generated bytes; the Humble Post battery owns full
machine accuracy and external ROM evidence.

## Verification

```powershell
dotnet test tests/Puck.HumbleGamingBrick.Forge.Tests/Puck.HumbleGamingBrick.Forge.Tests.csproj -c Release
```
