# The seated-avatar workload script: the debug world as played, its Moth avatar seated before the default third-person
# camera, at the shipped high preset with temporal reuse and indirect light off, so every frame rasterizes and lights
# every pixel afresh. Its counts hold the frame's mesh passes over the avatar's baked groups and the bake's field
# evaluations, which an avatar whose bake groups grow multiplies.
world.cadence off
world.quality high
world.temporal off
world.indirect off
world.rate pause
world.wait ready 180
world.rate resume
world.wait 30
world.counters --json
