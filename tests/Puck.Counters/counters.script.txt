# The puck counters workload script. The collector runs it on each backend's offscreen World, then closes it with
# wire.errors and quit, and reads the one world.counters --json response below.
# Every frame renders every pass, so the newest completed submission is a full frame rather than a re-composite.
world.cadence off
# The engine's pipeline set builds on the thread pool, and a cold driver cache can hold the first frame back for many
# ticks, so the read waits on the engine being ready rather than on a tick count. The deadline names the build if it
# never finishes. The simulation is paused meanwhile, so the ready tick, which differs by backend and cache, never
# reaches the state counts: both backends read them at the same completed tick.
world.rate pause
world.wait ready 180
world.rate resume
# Then a fixed number of ticks, so frames of the ready engine have completed before the read.
world.wait 120
world.counters --json
