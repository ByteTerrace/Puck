# Indirect Off preserves the authored fill

One static receiver carries green fill with no physical source. Its first Off
image and its Off image after a completed Medium solve must match exactly.
A separate pristine Off boot supplies the same exact reference. The completed
Medium image has no physical incoming light, so it differs from the Off image:
fill is replaced while indirect lighting is enabled.

The companion removes only fill. Its Off image remains stable through the same
toggle, but differs from the pristine filled reference and matches its own
unlit Medium image. Temporal reconstruction, AO and dynamic resolution are
disabled. The solve uses fenced readiness; Off captures use ordinary view and
capture completion. The real dual-backend observations remain owed.
