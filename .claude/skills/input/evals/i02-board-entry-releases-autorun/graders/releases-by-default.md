The response says the switch into the board releases autorun and the held run, and standing up does not bring autorun back.

PASS if it states that a mode switch releases input unless a transition keeps it, that the engagement switch keeps nothing, so run and the autorun toggle are released on sitting down and do not resume on standing up (the player re-actuates them). Example: "Sitting at the board is an engagement switch with an empty keep set, so run and the autorun latch are released; leaving the board never resumes a dormant toggle."

FAIL if it says autorun survives the board, resumes on leaving, or is suspended and restored. Example: "Autorun pauses while seated and picks up again when she stands."
