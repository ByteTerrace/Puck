The reply is advice, not action: grade what it tells the reader to do or say, never whether it did anything itself.

PASS if the reply's hunt plan names recurring hazard classes by name, including an invariant kept by convention (invalidation that relies on callers to clear) and at least one other named class, such as a cache that cannot help, recorded versus derived, or unbounded retention.
Example PASS: "Hunt each hazard by name: invalidation kept by convention, a cache that cannot help, unbounded retention of compiled programs."

FAIL if the reply gives a generic review checklist (style, tests, naming, performance) that names none of these classes.
Example FAIL: "Check the code style, that tests exist, and that the benchmark looks right."
