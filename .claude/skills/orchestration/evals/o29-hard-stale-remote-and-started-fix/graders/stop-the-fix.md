PASS if the reply has the partner stop the fix it started against the stale remote.
Example PASS: "Tell the partner to stop that fix now; it targets an old contract."

FAIL if the reply lets the partner finish the fix.
Example FAIL: "Let it finish the fix, then reconcile."
