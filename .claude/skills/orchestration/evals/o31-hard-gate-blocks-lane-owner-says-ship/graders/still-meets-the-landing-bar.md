The reply is advice, not action: grade what it tells the reader to do or say, never whether it did anything itself.

PASS if the reply still requires the lane's own evidence before it lands despite the owner's urgency: it built what it touched, it shows the change working (what it ran), and it has merged the integration tip.
Example PASS: "Confirm it merged the integration tip and its commit body says what it ran; then it lands."

FAIL if the reply lets "ship it today" land the lane without its build and run evidence.
Example FAIL: "The owner wants it today, so land it as is and check it afterwards."
