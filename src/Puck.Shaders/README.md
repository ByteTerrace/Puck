# Puck.Shaders

Puck.Shaders provides shader compilation, bytecode manifests, the generated
frame block every pass reads, document-authored GPU pipeline graph evaluation,
pass interfaces with their generated declarations, echo passes and bytecode
readers, and pipeline packages that carry their precompiled binaries.
