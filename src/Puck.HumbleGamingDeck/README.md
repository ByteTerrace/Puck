# Puck.HumbleGamingDeck

The deterministic NES/Famicom CPU and cartridge-bus core, with an integer
master clock and mid-instruction snapshots and forks.

Read the [Humble Gaming Deck manual](https://github.com/ByteTerrace/Puck/blob/main/docs/emulation/hgd/README.md) for
the implemented hardware, API behavior, and verification battery.
