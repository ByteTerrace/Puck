# Puck.HumbleGamingDeck

The deterministic NES/Famicom core on an integer master clock: the CPU and its
DMA unit, the PPU, the APU, controllers, and the NROM, MMC1 and MMC3 cartridge
boards over one owner of board memory (`HgdBoardMemory`), with
mid-instruction snapshots and forks, hosted through the `humble-gaming-deck`
machine engine.

Read the [Humble Gaming Deck manual](https://github.com/ByteTerrace/Puck/blob/main/docs/emulation/hgd/README.md) for
the implemented hardware, API behavior, and verification battery.
