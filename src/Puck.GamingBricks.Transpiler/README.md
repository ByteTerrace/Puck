# Puck.GamingBricks.Transpiler

Puck.GamingBricks.Transpiler compiles Puck DSL source to `puck.cartridge.v1`
documents and decompiles cartridge JSON back to `.puck` source.

## Documentation

- [Puck DSL cartridge transpilation](https://github.com/ByteTerrace/Puck/blob/main/docs/emulation/shared/cartridge-dsl.md) — grammar, operators, collections, and lowering.
- [Machine emulation manual](https://github.com/ByteTerrace/Puck/blob/main/docs/emulation/README.md) — architecture and related topics.
