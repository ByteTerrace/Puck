# Puck.Cli.Worktrees

Puck.Cli.Worktrees holds the worktree verbs: `lanes`, the lead's one-line-per-worktree roster and stall watch, `worktree-base`, the guard that resets a clean worktree to a base, and `worktree-report`, the removal report.
