# Puck.Cli.Worktrees

Puck.Cli.Worktrees holds the lead's lane and worktree verbs: `lanes`, the lead's one-line-per-worktree roster and stall watch, `worktree-report`, the removal report, and `evals`, which runs a skill's eval suite on a frozen worktree and compares results.
