# Puck.GamingBricks.Forge

Puck.GamingBricks.Forge provides source models, validation, canonical hashing,
and editing for the `puck.cartridge.v1` machine authoring format.

## Documentation

- [Cartridge Forge authoring](https://github.com/ByteTerrace/Puck/blob/main/docs/emulation/shared/cartridge-forge.md) — source models, pointer editing, compiler contracts, and authoring.
- [Machine emulation manual](https://github.com/ByteTerrace/Puck/blob/main/docs/emulation/README.md) — architecture and related topics.
- [Development and verification](https://github.com/ByteTerrace/Puck/blob/main/tests/Puck.GamingBricks.Tests/README.md).
