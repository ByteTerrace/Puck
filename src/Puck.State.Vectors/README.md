# Puck.State.Vectors

Puck.State.Vectors gives rules semantic vectors: typed access to a row's vector
column and the `mix`, `mean`, `nearest`, and `remember` transforms over a state
arena.

## Documentation

- [Vectors and embedding spaces](https://github.com/ByteTerrace/Puck/blob/main/docs/reference/state/vectors.md) — declaring spaces and vector rows, comparing vectors, and the transforms.
- [State and rules overview](https://github.com/ByteTerrace/Puck/blob/main/docs/reference/state.md) — the model these transforms write into.
