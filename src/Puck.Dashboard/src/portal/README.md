# puck-dashboard

This package implements World Studio and the authenticated portal pages. Its
studio loads verified official content and runs Puck.World.Browser for document
validation and previews. The [Puck.Dashboard reference](../../README.md) owns
the studio model, page behavior, setup, and verification workflow.

The local [package scripts](package.json) provide development serving, a
TypeScript and Vite build, regression tests, and schema-derived type generation
and checking. Engine-backed tests need the browser engine and official content
artifacts described in the parent reference.
