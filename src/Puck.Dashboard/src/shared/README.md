# byteterrace-shared

This directory contains TypeScript contracts and helpers imported by the
dashboard host and portal: service interfaces, the host store, onboarding,
and the typed request client. Both applications consume these files directly.

Its package manifest declares no independent build or test scripts. Verify
changes through the consuming applications using the
[dashboard development workflow](../../README.md#run-and-check).
