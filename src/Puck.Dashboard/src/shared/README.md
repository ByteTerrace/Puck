# Dashboard shared contracts

This directory contains TypeScript contracts and helpers imported by the
dashboard host and portal: service interfaces and the account setup
machine (onboarding). It is source only, with no package manifest of its
own: each application includes these files in its own compilation. Verify changes
through both applications using the
[dashboard development workflow](../../README.md#run-and-check).
