# Puck.HumbleGamingBrick.Forge

Puck.HumbleGamingBrick.Forge compiles `puck.cartridge.v1` documents into native
CGB ROMs, providing SM83 code emission, tile encoders, and boot-ROM tooling.

## Documentation

- [HGB cartridge compiler and firmware tooling](https://github.com/ByteTerrace/Puck/blob/main/docs/emulation/hgb/forge.md) — ROM compiler, memory layout, and boot ROMs.
- [Machine emulation manual](https://github.com/ByteTerrace/Puck/blob/main/docs/emulation/README.md) — architecture and related topics.
- [Development and verification](https://github.com/ByteTerrace/Puck/blob/main/tests/Puck.HumbleGamingBrick.Forge.Tests/README.md).
