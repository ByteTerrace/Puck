# Puck.AdvancedGamingBrick.Forge

Puck.AdvancedGamingBrick.Forge compiles `puck.cartridge.v1` documents into native
AGB ROMs, emitting Thumb-1 instructions, Mode-0 tile maps, and RGB555 palettes.

## Documentation

- [AGB cartridge compiler and native backend](https://github.com/ByteTerrace/Puck/blob/main/docs/emulation/agb/forge.md) — ROM compiler, memory layout, and Thumb-1 emitter.
