# Puck.Cli.Format

Puck.Cli.Format holds the convention rewriters (`puck format`, over C# and `.puck` sources), the strict format ledger (`puck formats`) and the pull-request formatter (`puck pull-request`), with `CliVocabularyResolver`, the document vocabularies the formatter and the world-authoring verbs resolve a source through.
