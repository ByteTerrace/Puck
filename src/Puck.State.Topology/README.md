# Puck.State.Topology

Puck.State.Topology answers board questions over a state arena: rays, board
shapes, and combinations of boards, plus pattern matching over sequences of
arena values.

## Documentation

- [Topologies and boards](https://github.com/ByteTerrace/Puck/blob/main/docs/reference/state/topologies.md) — board queries and masks.
- [Patterns](https://github.com/ByteTerrace/Puck/blob/main/docs/reference/state/patterns.md) — declaring and matching patterns.
- [State and rules overview](https://github.com/ByteTerrace/Puck/blob/main/docs/reference/state.md) — the model these queries read.
